# Security Audit — SIP-01/UNCAGED-Index-Relay — 2026-10-20

## Summary
Production Bun/OpenSearch Nostr index relay (TypeScript). Strong security posture: NIP-42 auth-gated kinds (4/1059) with explicit master-pubkey model, rejected signed-artifact kinds by default, far-future `created_at` rejection, per-connection inflight EVENT semaphore, OpenSearch bulk-queue backpressure with NACKs, NIP-77 record caps, query limit clamping enforced and advertised via NIP-11, transport-level max message size, careful IP_HEADER spoofing guidance, and a clean signing-key story (env `NOSTR_NSEC` or entrypoint-generated key persisted chmod-600, printed once). No committed secrets. Findings: 0 CRITICAL / 0 HIGH / 1 MEDIUM / 3 LOW.
